## 概要
あの頃のインターネットの原風景がここにある。
Windows 95/98風のレトロなUIと、現代のリアルタイム通信が融合した新感覚チャットアプリです。

懐かしのグレーウィンドウや無骨なボタンを採用しつつ、「ビデオ通話」「画面共有」「音声通話」など現代のコミュニケーション機能を網羅。ネイティブC++で作られた超軽量設計により、PCの負荷を最小限に抑えながらサクサク快適に高速動作します。ゲームや作業の裏で起動していても、PCの動作を妨げません。

## 動作環境
* **OS:** Windows 10, Windows 11 (64bit)

## インストール方法
ダウンロードしたアーカイブを適当なフォルダに解凍し、中にある `chat.exe` をダブルクリックして起動してください。

## アンインストール方法
解凍した `chat.exe` （および関連ファイルがある場合はそのフォルダごと）を削除してください。

> **※注意**
> 本ソフトは設定の保存にレジストリを使用しています。
> 完全に設定を消去したい場合は、レジストリエディタ（`regedit`）を起動し、以下のキーを削除してください。
> `HKEY_CURRENT_USER\Software\chat.exe`
