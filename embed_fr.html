chat.exe - Intégration site Web (iframe)

Ajoutez chat.exe à votre site Web !

La version Web de chat.exe peut être facilement intégrée à votre propre site Web ou blog à l'aide d'une balise iframe.
Pourquoi ne pas installer un salon de discussion rétro pour que vos visiteurs interagissent entre eux ?

■ Code d'intégration de base

Copiez et collez simplement le code HTML ci-dessous n'importe où sur votre site pour afficher le salon de discussion.

<iframe 
  src="https://app.chatexe.net/?room=MySiteRoom&showFrame=0&lang=fr" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

* En spécifiant allow="microphone; camera; display-capture", vous activez les appels audio/vidéo et le partage d'écran dans l'iframe.

■ Liste des paramètres URL

Vous pouvez personnaliser le comportement du chat en ajoutant des paramètres à la fin de l'URL dans l'attribut src sous le format ?paramètre=valeur. Connectez plusieurs paramètres en utilisant &.

Paramètre Défaut Description
room Lobby Spécifie le nom initial du salon. (ex : room=MySiteRoom)
private 0 Défini sur 1, le salon ne sera pas affiché dans la "Liste des salons publics", ce qui en fait un salon privé accessible uniquement à ceux qui connaissent le nom du salon.
showFrame 1 Défini sur 0, le cadre extérieur de la fenêtre est masqué, ce qui permet au chat de se fondre parfaitement dans le design de votre site. Recommandé pour l'intégration.
lang ja Spécifie la langue d'affichage. (ex : ja, en, zh-cn, zh-tw, ko, de, fr)
showUsers 1 Défini sur 0, le panneau de la liste des utilisateurs sur le côté droit est masqué.
showMoveRoom 1 Défini sur 0, le bouton "Changer de salon" est masqué, bloquant les utilisateurs dans le salon spécifié.
enableCamera 1 Défini sur 0, la fonction de diffusion de la caméra est désactivée.
enableMic 1 Défini sur 0, la fonction de diffusion du microphone est désactivée.
enableScreen 1 Défini sur 0, la fonction de partage d'écran est désactivée.
