chat.exe - Incorporação em site (iframe)

Adicione o chat.exe ao seu site!

A versão web do chat.exe pode ser facilmente incorporada ao seu próprio site ou blog usando uma tag iframe.
Por que não montar uma sala de chat retro como local de encontro para seus visitantes?

■ Código de incorporação básico

Basta copiar e colar o código HTML abaixo em qualquer lugar do seu site para exibir a sala de chat.

<iframe 
  src="https://app.chatexe.net/?room=MinhaSala&showFrame=0&lang=pt" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

* Ao especificar allow="microphone; camera; display-capture", as chamadas de áudio/vídeo e o compartilhamento de tela são habilitados dentro do iframe.

■ Lista de parâmetros de URL

Você pode personalizar o comportamento do chat adicionando parâmetros ao final da URL no atributo src no formato ?parâmetro=valor. Conecte vários parâmetros usando &.

Parâmetro Padrão Descrição
room Lobby Especifica o nome inicial da sala. (ex., room=MinhaSala)
private 0 Se definido como 1, a sala não aparecerá na "Lista de salas públicas", tornando-a uma sala privada acessível apenas para quem conhece o nome da sala.
showFrame 1 Se definido como 0, a moldura externa da janela é ocultada, permitindo que o chat se integre perfeitamente ao design do seu site. Recomendado para incorporação.
lang ja Especifica o idioma de exibição. (ex., ja, en, zh-cn, zh-tw, ko, de, fr, es, pt)
showUsers 1 Se definido como 0, o painel da lista de usuários no lado direito é ocultado.
showMoveRoom 1 Se definido como 0, o botão "Mudar de sala" é ocultado, bloqueando os usuários na sala especificada.
enableCamera 1 Se definido como 0, a função de transmissão da câmera é desativada.
enableMic 1 Se definido como 0, a função de transmissão do microfone é desativada.
enableScreen 1 Se definido como 0, a função de compartilhamento de tela é desativada.
