chat.exe - 網站嵌入 (iframe)

將 chat.exe 嵌入您的網站！

透過使用 iframe 標籤，您可以輕鬆地將 chat.exe 的網頁版嵌入到您的個人網站或部落格中。
不妨為您的訪客設置一個復古聊天室，提供一個交流的空間吧！

■ 基本嵌入程式碼

只需將以下 HTML 程式碼貼到您網站的任意位置，即可顯示聊天室。

<iframe 
  src="https://app.chatexe.net/?room=MySiteRoom&showFrame=0&lang=zh-tw" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

※ 指定 allow="microphone; camera; display-capture" 可在 iframe 內啟用語音/視訊通話和螢幕分享功能。

■ URL 參數列表

您可以透過在 src 屬性的 URL 末尾附加 ?參數名=值 的形式來客製化聊天的行為。使用 & 連接多個參數。

參數 預設值 說明
room 大廳 (Lobby) 指定初始進入的房間名。（例：room=MySiteRoom）
showFrame 1 設定為 0 將隱藏外部的復古視窗邊框，使其更好地融入您的網站設計。嵌入時推薦設定為 0。
lang ja 指定顯示語言。（如：ja, en, zh-cn, zh-tw, ko）
showUsers 1 設定為 0 將隱藏右側的用戶列表面板。
showMoveRoom 1 設定為 0 將隱藏「移動房間」按鈕，將用戶固定在指定的房間內。
enableCamera 1 設定為 0 將停用攝影機視訊串流功能。
enableMic 1 設定為 0 將停用麥克風語音串流功能。
enableScreen 1 設定為 0 將停用螢幕分享功能。
