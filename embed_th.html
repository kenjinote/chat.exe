chat.exe - การฝังเว็บไซต์ (iframe)

เพิ่ม chat.exe ลงในเว็บไซต์ของคุณ!

เวอร์ชันเว็บของ chat.exe สามารถฝังลงในเว็บไซต์หรือบล็อกของคุณได้อย่างง่ายดายโดยใช้แท็ก iframe
ทำไมไม่ลองตั้งค่าห้องแชทย้อนยุคเป็นสถานที่พบปะสำหรับผู้เยี่ยมชมของคุณล่ะ?

■ รหัสฝังพื้นฐาน

เพียงคัดลอกและวางโค้ด HTML ด้านล่างที่ใดก็ได้บนเว็บไซต์ของคุณเพื่อแสดงห้องแชท

<iframe 
  src="https://app.chatexe.net/?room=MySiteRoom&showFrame=0&lang=th" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

* การระบุ allow="microphone; camera; display-capture" จะเป็นการเปิดใช้งานการโทรด้วยเสียง/วิดีโอและการแชร์หน้าจอภายใน iframe

■ รายการพารามิเตอร์ URL

คุณสามารถปรับแต่งพฤติกรรมของแชทได้โดยเพิ่มพารามิเตอร์ต่อท้าย URL ในแอตทริบิวต์ src ในรูปแบบ ?พารามิเตอร์=ค่า เชื่อมโยงหลายพารามิเตอร์โดยใช้ &

พารามิเตอร์ ค่าเริ่มต้น คำอธิบาย
room Lobby ระบุชื่อห้องเริ่มต้น (เช่น room=MySiteRoom)
private 0 หากตั้งค่าเป็น 1 ห้องจะไม่ปรากฏใน "รายการห้องสาธารณะ" ทำให้เป็นห้องส่วนตัวที่เข้าถึงได้เฉพาะผู้ที่รู้ชื่อห้องเท่านั้น
showFrame 1 หากตั้งค่าเป็น 0 กรอบหน้าต่างด้านนอกจะถูกซ่อนไว้ ช่วยให้แชทผสานเข้ากับการออกแบบเว็บไซต์ของคุณได้อย่างกลมกลืน แนะนำเมื่อทำการฝัง
lang ja ระบุภาษาที่แสดง (เช่น ja, en, zh-cn, zh-tw, ko, de, fr, es, pt, ru, it, pl, nl, ar, th)
showUsers 1 หากตั้งค่าเป็น 0 แผงรายชื่อผู้ใช้ทางด้านขวาจะถูกซ่อนไว้
showMoveRoom 1 หากตั้งค่าเป็น 0 ปุ่ม "เปลี่ยนห้อง" จะถูกซ่อนไว้ ทำให้ผู้ใช้ถูกล็อกอยู่ในห้องที่ระบุ
enableCamera 1 หากตั้งค่าเป็น 0 ฟีเจอร์การแพร่ภาพจากกล้องจะถูกปิดใช้งาน
enableMic 1 หากตั้งค่าเป็น 0 ฟีเจอร์การแพร่ภาพจากไมโครโฟนจะถูกปิดใช้งาน
enableScreen 1 หากตั้งค่าเป็น 0 ฟีเจอร์การแชร์หน้าจอจะถูกปิดใช้งาน
