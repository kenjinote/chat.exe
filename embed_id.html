chat.exe - Situs Web Semat (iframe)

Tambahkan chat.exe ke Situs Web Anda!

Versi web dari chat.exe dapat dengan mudah disematkan ke situs web atau blog Anda menggunakan tag iframe.
Mengapa tidak mengatur ruang obrolan retro sebagai tempat berkumpul untuk pengunjung Anda?

■ Kode Semat Dasar

Cukup salin dan tempel kode HTML di bawah ini di mana saja di situs web Anda untuk menampilkan ruang obrolan.

<iframe 
  src="https://app.chatexe.net/?room=MySiteRoom&showFrame=0&lang=id" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

* Menentukan allow="microphone; camera; display-capture" memungkinkan panggilan suara/video dan berbagi layar di dalam iframe.

■ Daftar Parameter URL

Anda dapat menyesuaikan perilaku obrolan dengan menambahkan parameter ke URL dalam atribut src menggunakan format ?parameter=value. Gabungkan beberapa parameter menggunakan &.

Parameter Bawaan Deskripsi
room Lobby Tentukan nama ruang awal (mis. room=MySiteRoom)
private 0 Jika diatur ke 1, ruang tidak akan muncul di "Daftar Ruang Publik", menjadikannya ruang pribadi yang hanya dapat diakses oleh mereka yang mengetahui nama ruang tersebut.
showFrame 1 Jika diatur ke 0, bingkai jendela luar akan disembunyikan, memungkinkan obrolan berpadu mulus dengan desain situs web Anda. Disarankan saat menyematkan.
lang ja Tentukan bahasa tampilan (mis. ja, en, zh-cn, zh-tw, ko, de, fr, es, pt, ru, it, pl, nl, ar, th, hi, bn, id)
showUsers 1 Jika diatur ke 0, panel daftar pengguna di sebelah kanan akan disembunyikan.
showMoveRoom 1 Jika diatur ke 0, tombol "Ganti Ruang" akan disembunyikan, mengunci pengguna di ruang yang ditentukan.
enableCamera 1 Jika diatur ke 0, fitur siaran kamera akan dinonaktifkan.
enableMic 1 Jika diatur ke 0, fitur siaran mikrofon akan dinonaktifkan.
enableScreen 1 Jika diatur ke 0, fitur berbagi layar akan dinonaktifkan.
