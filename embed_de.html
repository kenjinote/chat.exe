chat.exe - Website-Einbettung (iframe)

Füge chat.exe zu deiner Website hinzu!

Die Webversion von chat.exe kann mithilfe eines iframe-Tags ganz einfach in Ihre Website oder Ihren Blog eingebettet werden.
Warum richten Sie nicht einen Retro-Chatroom als Treffpunkt für Ihre Besucher ein?

■ Grundlegender Einbettungscode

Kopieren Sie einfach den folgenden HTML-Code an eine beliebige Stelle auf Ihrer Website, um den Chatroom anzuzeigen.

<iframe 
  src="https://app.chatexe.net/?room=MySiteRoom&showFrame=0&lang=de" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

* Durch Angabe von allow="microphone; camera; display-capture" werden Audio-/Videoanrufe und Bildschirmfreigabe im iframe ermöglicht.

■ Liste der URL-Parameter

Sie können das Verhalten des Chats anpassen, indem Sie Parameter an das Ende der URL im src-Attribut im Format ?Parameter=Wert anhängen. Verbinden Sie mehrere Parameter mit &.

Parameter Standardwert Beschreibung
room Lobby Gibt den anfänglichen Raumnamen an. (z. B. room=MySiteRoom)
private 0 Wenn auf 1 gesetzt, wird der Raum nicht in der "Liste öffentlicher Räume" angezeigt, sodass es sich um einen privaten Raum handelt, der nur denjenigen zugänglich ist, die den Raumnamen kennen.
showFrame 1 Wenn auf 0 gesetzt, wird der äußere Fensterrahmen ausgeblendet, wodurch sich der Chat nahtlos in das Design Ihrer Website einfügt. Empfohlen für die Einbettung.
lang ja Gibt die Anzeigesprache an. (z. B. ja, en, zh-cn, zh-tw, ko, de, fr)
showUsers 1 Wenn auf 0 gesetzt, wird das Benutzerlisten-Fenster auf der rechten Seite ausgeblendet.
showMoveRoom 1 Wenn auf 0 gesetzt, wird die Schaltfläche "Raum wechseln" ausgeblendet, sodass Benutzer auf den angegebenen Raum festgelegt sind.
enableCamera 1 Wenn auf 0 gesetzt, wird die Kameraübertragungsfunktion deaktiviert.
enableMic 1 Wenn auf 0 gesetzt, wird die Mikrofonübertragungsfunktion deaktiviert.
enableScreen 1 Wenn auf 0 gesetzt, wird die Bildschirmfreigabefunktion deaktiviert.
