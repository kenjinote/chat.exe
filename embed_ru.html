chat.exe - Встраивание на сайт (iframe)

Добавьте chat.exe на свой сайт!

Веб-версию chat.exe можно легко встроить на ваш собственный веб-сайт или блог с помощью тега iframe.
Почему бы не создать ретро-чат как место встречи для ваших посетителей?

■ Базовый код для встраивания

Просто скопируйте и вставьте приведенный ниже HTML-код в любое место на вашем сайте, чтобы отобразить чат.

<iframe 
  src="https://app.chatexe.net/?room=MySiteRoom&showFrame=0&lang=ru" 
  width="100%" 
  height="500" 
  frameborder="0"
  allow="microphone; camera; display-capture"
></iframe>

* Указав allow="microphone; camera; display-capture", вы разрешите аудио/видео звонки и демонстрацию экрана внутри iframe.

■ Список URL-параметров

Вы можете настроить поведение чата, добавив параметры в конец URL-адреса в атрибуте src в формате ?параметр=значение. Соединяйте несколько параметров с помощью &.

Параметр По умолчанию Описание
room Lobby Указывает начальное название комнаты. (например, room=MySiteRoom)
private 0 Если установлено значение 1, комната не будет отображаться в «Списке публичных комнат», что сделает ее приватной комнатой, доступной только тем, кто знает ее название.
showFrame 1 Если установлено значение 0, внешняя рамка окна скрывается, что позволяет чату легко вписаться в дизайн вашего сайта. Рекомендуется для встраивания.
lang ja Указывает язык интерфейса. (например, ja, en, zh-cn, zh-tw, ko, de, fr, es, pt, ru)
showUsers 1 Если установлено значение 0, панель списка пользователей с правой стороны скрывается.
showMoveRoom 1 Если установлено значение 0, кнопка «Сменить комнату» скрывается, блокируя пользователей в указанной комнате.
enableCamera 1 Если установлено значение 0, функция трансляции с камеры отключается.
enableMic 1 Если установлено значение 0, функция трансляции с микрофона отключается.
enableScreen 1 Если установлено значение 0, функция демонстрации экрана отключается.
