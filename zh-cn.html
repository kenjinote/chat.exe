■ 应用简介

互联网的原始风貌就在这里。
融合了 Windows 95/98 复古 UI 与现代实时通信的全新聊天应用！

没有“点赞”，没有“关注”，没有广告，没有推荐算法，也不会被 AI 抓取学习。重现那个无法与任何人攀比、纯粹而朴素的“因特网”氛围。

“chat.exe” 是一款令人回想起昔日电脑通信时代经典设计的通信应用。在采用怀旧的灰色窗口和粗犷按钮的同时，完全涵盖了不仅是文本聊天，还包括“视频通话”、“屏幕共享”、“语音通话”等现代功能。

虽然外观复古，但后台运行的音视频压缩通信技术已经使用现代最新技术（如 H.264 硬件编码和 Opus 音频编解码器等）完全重建，实现了与外观截然相反的高品质、极度流畅的通信。

■ 主要功能与使用方法

✨ 复古情怀 UI
致敬当年操作系统的怀旧设计。没有多余装饰的经典窗口，让心情瞬间高涨。

🎥 视频＆语音通话・屏幕共享
不仅支持文字，标配支持使用网络摄像头和麦克风进行通话，以及电脑屏幕共享。

 🎨 自由的文本装饰
支持粗体、斜体、更改文字颜色和大小等，让你可以用自己的方式展现昔日热闹聊天室的氛围。

🚀 极速响应
告别臃肿的通话应用。采用 C++ 原生开发，将冗余精简到极致的超轻量级设计。

■ 运行环境

  • OS: Windows 10 / 11 (仅限64位)
  • CPU: Intel Core i3 或以上
  • 内存: 4GB及以上
  • 其他: 需要互联网连接，网络摄像头・麦克风（使用视频通话时）

■ 隐私政策

本应用使用经过服务器的实时通信，但开发者的服务器不会永久保存或收集通话内容、视频画面以及聊天记录。此外，本应用包含防垃圾信息功能。
